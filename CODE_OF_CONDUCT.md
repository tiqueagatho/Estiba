# Código de conducta

Este proyecto adopta el
[Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

En resumen: sé **respetuoso y constructivo**. No se toleran el acoso, los
insultos ni la discriminación por ningún motivo. Las críticas técnicas son
bienvenidas; los ataques personales, no.

Los mantenedores pueden editar, cerrar o rechazar contribuciones y comentarios
que incumplan esta norma.

Para reportar un problema de conducta, contacta en privado con el mantenedor
([@tiqueagatho](https://github.com/tiqueagatho)) o, si es sensible, usa la
pestaña **Security**.
